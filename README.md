This starter kit deploys production-ready generative AI infrastructure on Huawei Cloud CCE (Cloud Container Engine) with a single CLI command: LLM serving engine (vLLM), AI gateway (LiteLLM, OpenAI-compatible unified endpoint), vector database (Qdrant), embedding service (TEI), and chat frontend (Open WebUI) are installed as a component catalog, while the underlying infrastructure is provisioned declaratively with Terraform. It targets DevOps / AI platform / backend engineers as a reference architecture, learning sample, or production template.
